Gameplay helpers

      

        Server-side tweaks from the Valheim UI Gameplay plugin. Changes apply live —
        the plugin reloads its config on write, so no restart is needed.
      

      

        
Autofeed

        

          Feeds hungry tamed animals from chests marked with a sign. Place a sign
          reading the prefix below within the sign radius of a chest full of food.
          Any unmodded client can place the sign — players install nothing.

          Raids checked below never start on their own. The event command can still
          start them deliberately.

        A snapshot is taken automatically before every install and uninstall.
        Restoring replaces the managed plugin set, then restart the server.

        Players are disconnected either way.
